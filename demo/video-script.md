# DealSense demo video script (under 3 minutes)

Record after the full build. Script, shot by shot:

**0:00 – 0:20 — The problem**
"Shopping in India means opening ten tabs. Prices change daily, reviews
are scattered, and the cheapest listing is sometimes a trap."
Show: messy browser tabs, price confusion.

**0:20 – 0:45 — The ask**
Type one query into DealSense:
"RTX 4060 laptop under ₹80,000 in India right now"
Show: the CLI / UI, single plain-language query.

**0:45 – 1:45 — The agent working (live)**
Show the agent calling SerpApi live — real results streaming in, no
cached data. Narrate: "Every price you see was fetched seconds ago from
live merchant listings via SerpApi."
Show: ranked table — price, merchant, rating side by side.

**1:45 – 2:30 — The recommendation**
"The cheapest is ₹74,990 at X — but 3.2 stars. For ₹2,000 more, this one
is 4.6 stars with 800 reviews. DealSense picks this one."
Show: the verdict + buy link.

**2:30 – 3:00 — Close**
"DealSense: live market intelligence for Indian shoppers. Built for the
SerpApi India Hackathon 2026, Track 4 — Commerce & Market Intelligence."
Show: repo link on screen.
